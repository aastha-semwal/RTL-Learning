# Day 18 - 4-bit Up/Down Counter

## Objective

Design and verify a 4-bit Up/Down Counter using Verilog HDL.

---

## Theory

An Up/Down Counter is a sequential circuit that can count in both upward and downward directions based on a control signal.

If up_down = 1 → Counter increments.

If up_down = 0 → Counter decrements.

---

## Inputs

- clk
- reset
- up_down

---

## Output
